# AquaCore Models

Catalogue des modèles Ollama proposés par AquaCore.

Ce dépôt contient un fichier JSON public utilisé par AquaCore pour :
- proposer de nouveaux modèles compatibles
- indiquer les modèles recommandés
- aider l'utilisateur à choisir un modèle selon son poste

Fichier principal :
- `aquacore-models.json`
